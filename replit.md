# إنطلاقة HPC — Static Website

A Bootstrap-based multi-page Arabic website for HPC (إنطلاقة), focused on sustainable kinetic energy.

## Pages
- `index.html` — Home / landing page
- `about.html` — About
- `contact.html` — Contact
- `feature.html` — Features
- `404.html` — Not found

## Stack
- Plain HTML, CSS, JavaScript (no build step)
- Bootstrap (local copy in `css/bootstrap.min.css`)
- Custom styles in `css/style.css`
- JS in `js/main.js` + third-party libs in `lib/`

## How to run
```
python3 -m http.server 5000
```
The workflow "Start application" is already configured and will serve the site at port 5000.
